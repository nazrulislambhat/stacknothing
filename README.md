# STACKNOTHING LLC // Agency & Product Ecosystem

Hard-edged engineering, standalone digital utilities, UI components, and high-performance agency architecture built with Next.js 16.

---

## 🚀 Current Features

- **Next.js 16 Core Integration**: Leveraging native Turbopack, App Router, and server-side rendering pipelines.
- **Brutalist Design System**: High-contrast hard borders (`2px solid`), sharp structural grid lines, and vivid neon accents (Acid Green, Cyan, Hot Magenta).
- **Dynamic Theme Toggle**: Seamless client-side switching between stark Dark and Light modes with persisted local storage state.
- **Dual Currency Pricing Engine**: Instant conversion support between USD ($) and INR (₹) across engagement tiers.
- **Ecosystem & Client Showcase**: Dedicated directories highlighting active client builds, past agency work, and consumer apps like _dhikrly.com_.
- **Interactive Navigation**: Dropdown service routing for Custom Web/App Development, E-commerce, Cross-Platform Mobile Apps, and UI/UX Systems.

---

## ⚙️ Deployment Strategy

Our production environment is architected for zero-downtime, edge-optimized performance:

- **Hosting & Edge Delivery**: Deployed globally via [Vercel](https://vercel.com) leveraging Edge Middleware and ISR (Incremental Static Regeneration) for high-traffic routes.
- **CI/CD Pipeline**: Automated GitHub Actions workflow handling continuous integration:
  - **Linting & Type-Checking**: Strict ESLint and TypeScript compilation checks on every Pull Request.
  - **Automated Testing**: Unit and integration test suites execution prior to merge.
- **Preview Deployments**: Automatic ephemeral preview URLs generated per PR for staging verification and client sign-off.
- **DNS & Edge Security**: Managed securely via Cloudflare handling global SSL termination, DDoS protection, and custom DNS routing.
